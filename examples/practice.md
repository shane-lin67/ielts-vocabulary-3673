# 一轮闪卡 + 一篇故事

以下是练习示例，不是工具自动安排的课程。

## 一个词的记录会怎样变化

| 本次回答 | 累计不认识的点数 | 连续认识次数 |
|---|---:|---:|
| 不认识 | 1 | 0 |
| 不认识 | 2 | 0 |
| 认识 | 2 | 1 |
| 认识 | 2 | 2 |
| 认识 | 2 | 3 |
| 再次不认识 | 3 | 0 |

达到 2 点后会进入顽固词筛选。连续认识 3 次时计入看板的“当前掌握”，但不抹掉旧点数。如果同一天反复点击认识，程序也会累计；请自己按真实回忆结果作答。

## 配合故事

1. 在“自然地理”章节刷一小组词，记住回忆不出的词。
2. 打开故事页，选择相同章节。可以用搜索查某个难词，找包含它的故事。
3. 读英文，猜词义；对照中文后，听两三句，把整块表达读出来。
4. 关掉原文，用几个目标词说一两句自己的话。
5. 回到闪卡再测。两边的完成标记不会互相代填。

给 AI 的示例请求：

> 我刚练了自然地理章节，下面这些词还卡住：[填写词表]。请参考配套 Skill，先每次抽查一个，再让我用它造句。不要因为我看过答案就记作掌握。

只读 Skill 的 AI 无法自动知道浏览器里的学习进度，需由你提供待练词和练习结果。
